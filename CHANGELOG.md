## [0.4.0]

- Added `source.ordinator`, `source.ordinator.sortImports` and `source.ordinator.sortExports` code actions, usable with `editor.codeActionsOnSave` to sort imports and/or exports on save.
- Added `Ordinator: Sort Imports` and `Ordinator: Sort Exports` commands.
- Added `ordinator.languages`, `ordinator.sortSpecifiers` and `ordinator.includeRequire` settings.
